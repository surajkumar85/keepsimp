KeepSimp audio workspace: third-party components
=================================================

The audio editor and its pages run these components in your browser. KeepSimp itself is
licensed under AGPL-3.0-only (see LICENSE in the repository). Source code for every
component is available from the links below.

The LGPL components (LAME and FFmpeg's AAC encoder) are separate, unmodified WebAssembly
modules, loaded only when a file is written in their format: LAME for every MP3, and
FFmpeg's AAC encoder only where the browser's own does not give back every sample.
Their source code is at the links above.

The Whisper models are downloaded from this site the first time a transcription starts,
at the exact revisions named in lib/audio/whisper-models.json in the repository, each file
checked against its SHA-256 when the site is built.
