# Color utility

## Goal and implementation plan

The color workspace lives at `/dashboard/color-utility/`. It is one developer tool in the existing single-sidebar layout. It uses the developer category token and its own Tabler palette icon. KeepSimp’s semantic colors, typography, radii and compact control sizes remain the authority.

1. **Research and color engine.** Use Color.js 0.7.1 for CSS parsing, color-space conversion, white-point adaptation, gamut mapping, interpolation and ΔE2000; calculate WCAG contrast with its normative luminance weights. Bound inputs, preserve the original color and alpha, identify sRGB fallbacks and test known numerical results.
2. **Product workflows.** Build seven compact tabs: Convert, Palettes, Contrast, Gradients, From image, Brand colors and Batch. Keep all document data in memory. Make copy, reorder, lock, undo, explicit replacement and actual downloadable exports work on desktop and mobile.
3. **References and guidance.** Bundle sourced company swatches, distinguish published palettes from samples of first-party assets, and include scope and a checked date. Add illustrated blog guides, metadata, sharing cards and catalogue discovery for the completed tool.
4. **Verification and release.** Run the repository checks and production browser tests. Verify exact outputs, invalid inputs, opacity, bounds, clipboard/download journeys, both themes, keyboard access, 320px layouts and real offline use with the server stopped. Inspect screenshots, then commit and push only this work to `main`.

The UI-only redesign is planned and documented in [Color experience redesign](color-experience.md). The numerical engine and all export/sampling bounds remain unchanged.

## Research

| Reference                                                                                                                                                               | Decision                                                                                                                                                                                                                                                             |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [W3C CSS Color 4](https://www.w3.org/TR/css-color-4/)                                                                                                                   | Support absolute CSS color values. Do not resolve page variables, currentColor, relative colors, calc, missing channels or pasted expressions. Color 4 is still a draft; the supported parser is the pinned library, not every syntax in the evolving specification. |
| [Color.js spaces](https://colorjs.io/docs/spaces), [gamut mapping](https://colorjs.io/docs/gamut-mapping.html), [interpolation](https://colorjs.io/docs/interpolation)  | Preserve source coordinates for wider spaces; use CSS chroma-reduction gamut mapping for sRGB preview/HEX exports. Mix with premultiplied alpha.                                                                                                                     |
| [WCAG 2.2](https://www.w3.org/TR/WCAG22/#contrast-minimum)                                                                                                              | Use the normative 0.2126 / 0.7152 / 0.0722 linear-sRGB luminance weights and compute sRGB source-over composition over an explicitly opaque canvas. Judge thresholds against the unrounded ratio, not its two-decimal display.                                       |
| [Machado 2009 paper](https://pubmed.ncbi.nlm.nih.gov/19834201/), [published matrices](https://www.inf.ufrgs.br/~oliveira/pubs_files/CVD_Simulation/CVD_Simulation.html) | Use the three severity-1.0 matrices in linear sRGB. These are approximate previews; grayscale uses luminance.                                                                                                                                                        |
| [MDN EyeDropper](https://developer.mozilla.org/en-US/docs/Web/API/EyeDropper)                                                                                           | Capability-gated and started only by a click. Native color and local image sampling remain available when screen picking is unsupported.                                                                                                                             |
| [Design Tokens format](https://www.designtokens.org/tr/drafts/format/)                                                                                                  | Export color tokens as `$type: color` with explicit sRGB components and alpha. This is palette data, not a claim that arbitrary destination tooling accepts it without adaptation.                                                                                   |

## Delivered behavior

- **Convert:** HEX (3/4/6/8 digits), named CSS colors, RGB, HSL, HWB, Lab/LCH D50, OKLab/OKLCH, Display P3, linear sRGB, Adobe RGB compatible, ProPhoto, Rec. 2020 and XYZ D50/D65. Also simple HSV/HSB and CMYK input/output. Modern absolute color functions use the library parser. Missing components and contextual CSS are refused. RGB/HEX/HSL/HWB/HSV/CMYK use a mapped sRGB fallback when necessary; other formats preserve the original coordinate conversion. Common formats appear first; a native disclosure holds the other spaces. Copy values or use the large inline saturation/brightness picker, hue/opacity tracks, exact channel controls and supported screen eyedropper. Hue is retained through gray or black; changing opacity alone preserves the original color space.
- **Palettes:** six OKLCH hue harmonies, an eleven-step lightness scale, mixing in four spaces, up to twelve custom colors, locks, shuffle, reorder, remove and twenty changes of undo history. The tonal scale caps chroma at 0.16 and does not claim compatibility with another system’s numbered scales. Current colors are added explicitly; a full palette disables adding instead of discarding an existing color. Individual swatch edits are previewed as drafts and applied once, with undo. Harmony, tones and mixing share one focused exploration panel.
- **Contrast:** alpha-aware WCAG AA/AAA normal/large text and non-text thresholds, an opaque passing-color suggestion, explicit application, three approximate vision previews plus grayscale, and ΔE2000 without opacity. No APCA conformance or whole-site accessibility claim.
- **Gradients:** linear/radial/conic, two to eight ordered stops, angles and sRGB/linear sRGB/OKLab/OKLCH interpolation. Equal-position stops retain hard edges. Export has a 33-point sampled fallback plus original stops, followed by modern CSS; the fallback approximates intervals between samples.
- **From image:** signature-checked browser decoding of PNG/JPEG/WebP/GIF up to 10 MiB and 30 million pixels, resized to at most 256 × 256 pixels and converted to sRGB by canvas. Weighted 4-bit RGB bins and an OKLab separation threshold find representative colors; pixels below 50% opacity are ignored. Click or use equivalent coordinate fields to select a preview pixel, including alpha. The canvas may be displayed larger, but coordinates remain those of the bounded sampling grid; a marker shows the last sampled point. GIF uses the browser-decoded frame; animation is not preserved. No external image URLs or SVG image input.
- **Brand colors:** twelve company references with sources, scope and a 13 October 2026 checked date. A visual company chooser opens one reference at a time. Swatches can be copied, selected in context, deliberately opened in Convert and loaded as a palette. No company logos are included. These are references, not affiliations or licences to use an identity.
- **Batch:** up to 100 lines / 52,000 characters. Per-line errors retain order; copy or download actual HEX, RGB or OKLCH results. Editing the input or format clears old results.

## Precision, exports and data

Single color input is limited to 512 characters. Coordinates must be finite and at most one million in magnitude. Parsed alpha is clamped to 0–1. HSV uses degrees and percentages, and CMYK percentages; these two models omit alpha. CMYK is a simple mathematical RGB conversion without an ICC profile or spot-color matching, unsuitable as a press-ready ink prescription.

Most displayed conversions use seven significant digits; HSV/CMYK use four decimal places. Internal mixed-color strings keep twelve significant digits to avoid a round-trip changing an 8-bit midpoint. HEX and preview swatches round to eight-bit channels and alpha. Contrast computes floating-point values before display rounding. Exported suggestions are rechecked against the requested contrast threshold.

Palette exports: CSS, SCSS, JSON, Design Tokens JSON, a Tailwind config fragment, GIMP GPL text, SVG and PNG strips. Data is normalized and generated by the engine: text pasted by a user is never placed directly into SVG or CSS. CSS/SCSS/JSON/tokens/Tailwind/SVG/PNG retain opacity; GPL contains opaque channel values. Every export uses the sRGB fallback. PNG strips contain color only, without arbitrary user-supplied text or remote resources.

Color literals in `lib/color/` are sample/reference data, not product theme values. Data swatches, gradient previews and intentional contrast samples use computed inline color styles. All surrounding UI uses semantic tokens; contrast samples are marked `data-color-preview` so accessibility tests can exclude the intentionally failing sample while evaluating the tool’s controls. This exception must not be used on product buttons or normal explanatory text.

There is no document persistence, upload, network processing, account or remote palette fetch. The bounded operations run in the page; image analysis has at most 65,536 pixels and 4,096 bins, and cannot grow with the original file’s pixel count. Browser decoding happens before the 30-million-pixel guard. Files, input values and palette history clear on refresh. Existing app/theme storage is unchanged. The existing production service worker saves the tool’s static route and bundles; its architecture is unchanged.

## Brand provenance

`lib/color/brands.ts` retains each first-party source and scope. Anthropic’s public brand-guidelines file is treated as reference data, not instructions to restyle KeepSimp. Google follows its published Assistant core palette; Slack follows its dated September 2020 PDF; IBM uses selected design-language values; Discord follows its current three-color page; Linear includes only its two published wordmark colors. Meta’s selected stops and wordmark fill come from the SVG linked by its brand page (`https://static.xx.fbcdn.net/rsrc.php/y9/r/tL_v571NdZ0.svg`); Spotify uses `https://developer-assets.spotifycdn.com/images/guidelines/design/colors.svg`; Microsoft uses a clearly labelled subset of its Fluent UI DefaultPalette, not the corporate logo. GitHub’s current toolkit and Vercel’s Geist page supply their displayed values. Netflix’s first-party hosted 2020 symbol guide supplies its two reds and black background. These subsets are not claimed as complete current UI systems.

## Verification

Release verification on 13 October 2026 uses the actual numerical engine, decoded pixels and downloaded bytes. No color processing is mocked.

- `npm run check` passed design checks, formatting, lint, production static build, TypeScript and 2,234 unit cases in 129 files after integrating PDF editor commit `9135788`. The 131 selected pure modules had 100% statements, branches, functions and lines covered.
- The final color engine has 97 unit cases, including an additional normative WCAG coefficient reference. Its three selected logic modules have 100% coverage: 210 statements, 144 branches, 62 functions and 187 lines. A final format/lint/build/type check and all 107 color/blog/manifest unit cases passed after those final changes. Production dependency audit reported zero vulnerabilities.
- The shared production browser run included 220 cases across Chromium, Firefox, WebKit, Pixel 7 emulation and iPhone 13 emulation: 215 passed, two keyboard-only phone cases were skipped, and three existing JSON journeys failed in the concurrent run. All three were subsequently verified in four serial Firefox/iPhone JSON reruns; no JSON processing code was changed. These are reruns, not a claim that the original broad run was entirely green.
- The color release has 50 journeys (ten per profile), covering conversions/alpha/gamut, clipboard behavior, brand provenance and local browsing, palette locking/reordering/undo, actual JSON/tokens/SVG/transparent PNG downloads, numerical contrast/suggestions, gradient CSS/hard stops, real image pixels/type checks, batch errors, both-theme axe checks, narrow/reflow layouts, offline processing with the server stopped and four guide dates/metadata. All 50 passed in the final isolated production run (2.6 minutes).
- Desktop and 320px mobile screenshots in both themes, plus light palette/gradient/brand views, were inspected. Reflow at 720px represents the CSS space of a 1440px screen at 200% zoom; it does not claim testing of native browser zoom controls. Automated contrast samples are excluded only where the sample intentionally uses a failing user-selected pair. Axe checks use reduced motion so theme transitions have settled.

For simultaneous checkouts, use a dedicated test port, `reuseExistingServer: false` and `serve --no-port-switching`. Otherwise the CLI can switch its own port while Playwright reads another checkout's server. The full platform suite used its standard port; the final color-only run uses an external temporary configuration with an isolated port. Reports, screenshots and that temporary configuration are not committed.

Headless tests check screen-picker capability, not its native OS overlay. Physical phones, a manual screen-reader session, calibrated displays and printer profiles were not tested.
